# Erii Distribution

npm monorepo for distributing [ERII](https://github.com/spcookie/erii) — a Kotlin/JVM-based AI agent framework.

## Packages

| Package | Description |
|---------|-------------|
| `@spcookie/erii` | Main distribution with CLI entry point |
| `@spcookie/erii-core` | Core agent libraries |
| `@spcookie/erii-deps` | Third-party dependencies (JARs) |
| `@spcookie/erii-browser` | Browser automation driver |
| `@spcookie/erii-config` | Default configuration files |
| `@spcookie/erii-plugins` | Optional plugins (speech, QQ, etc.) |
| `@spcookie/erii-cli-*` | Platform-specific CLI binaries |
| `@spcookie/erii-runtime-*` | Platform-specific runtime binaries |
| `@spcookie/create-erii` | Project scaffolding tool |

## Requirements

- Node.js >= 18
- Java 21+ (runtime)
