# @spcookie/erii-browser-driver

Erii browser driver — Java classpath code for Playwright browser automation.

This package contains the thin Java driver JAR (`driver-1.57.0.jar`) that provides the
`com.microsoft.playwright.impl.driver` classes. Platform-specific native libraries are provided by the corresponding
optional platform packages:

- `@spcookie/erii-browser-driver-darwin-arm64`
- `@spcookie/erii-browser-driver-darwin-x64`
- `@spcookie/erii-browser-driver-linux-arm64`
- `@spcookie/erii-browser-driver-linux-x64`
- `@spcookie/erii-browser-driver-win32-x64`
